## 样式修改
- 整个系统
  1、最小文字字号 设置成12px 
  2、input框 textarea等表单控件 焦点触发时候 有两个边框 默认需要展示外边框（当前展示的是内边框） 焦点的时候 也只展示外边框 内边框不展示 
- 左侧的菜单单独提取成一个组件 组件名称 叫做Menu 不要叫AppShell
  1、工作流工作室 改成 AI 工作流
  2、不要显示Acme团队这个小卡片了
  3、左侧菜单 节点库 这个菜单及页面删掉
  4、下面的 MCP 网管可用 这一行 也删掉
- 右侧的内容
  1、只有右侧的内容 才是需要使用vue-router部分的内容
  2、整个右侧的内容 应该是一个大的组件 这个组件分成上下两部分  上面一部分 我们叫做header 下面那部分叫content  header部分的左边的是导航  文字大小改成14px  右侧的内容是自定义的 content部分宽度最大宽度为1440px 滚动条在content中设定 这样 顶部就可以固定了

- 页面拆解
 例如：\apps\web\src\pages\KnowledgePage.vue  目录结构应该是：
 knowledge-page
    index.vue
    components
      xxx.vue  具体的组件
尽量每个组件负责一个功能 而不是整个放在一个页面中

- 知识库页面改造
 1、页面布局改成左中右三个部分  左侧是知识库分组  中间是选中知识库后的列表 右侧的是检索测试 
 2、当前已接入知识库 CRUD、文档列表、切片与 PostgreSQL 全文检索；对象存储、ingest、向量/混合检索和对象签名预览未配置时会返回稳定错误码。 这个不要了
 3、错误信息 通过toast展示 不要有占位
 4、内容区域 分成三个部分后 这三个占满屏幕的剩余空间 超出后 在每个容器的内部展示滚动条
